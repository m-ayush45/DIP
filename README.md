1.HighPass
📂 High-Pass Filtering in Grayscale Image using OpenCV
🔍 Overview
This script loads a grayscale image and applies two types of high-pass filters (3x3 and 5x5 kernels) to enhance edges and fine details. The result is displayed using Matplotlib.
📌 Features
Load an image in grayscale.
Apply:
A standard 3×3 high-pass filter
A stronger 5×5 high-pass filter
Visualize the original and filtered images side-by-side.

2.HistogramMatching
Histogram Matching in Grayscale Images
This project demonstrates histogram matching between two grayscale images using Python. The goal is to adjust the pixel intensity distribution of a source image to match that of a reference image.
Using the match_histograms function from the skimage library, the source image is transformed to resemble the reference in terms of tone and contrast. The script visualizes:
The original source image
The reference image
The histogram-matched result
Additionally, histograms of all images are compared to show the alignment between the source and the reference.
